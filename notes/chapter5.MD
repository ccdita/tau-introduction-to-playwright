# Chapter 5

## Chapter 5 - Troubleshooting Test Issues

### What's in the Trace?
- List of commands of each step on the left side + the state of each step upon hover
- The call that threw an error
- Browser console
- Network tab for API testing

### Adding breakpoints in VSCode
- You can add/remove breakpoints in VSCode
- Manage breakpoints in the Run and Debug tab
- The test will stop running at the breakpoint
- Delete an error message to clean the test and refresh the test session

### Using the Command Line
- Use the flag `--debug` to run debug mode or `--ui` to run UI mode
